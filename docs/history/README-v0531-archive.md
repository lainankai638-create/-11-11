# 紧急修复：系统授权成功却立即停止

V0.4.7.4 的精准诊断记录显示失败于 `onStartCommand:127`："没有取得系统授予的录屏令牌"。实际根因是旧代码用 `-1` 表示缺少授权结果，然而安卓 `Activity.RESULT_OK` 恰好就是 `-1`；成功的授权被误判为失败。V0.4.7.5 把两个屏幕采集服务都改为使用 `Activity.RESULT_OK` 验证并单独检查授权数据，修复同类问题。这里没有 Android SDK，尚未实机编译；后续若出现其它错误，以新版诊断为准。

# 欧南 · 第二大脑 V0.4.7.5（录屏授权判断修复版）

**这是一份 Android 源码工程 ZIP，不是直接安装的 APK。** 工程继承手机已验证可编译的 V0.4.x 家族，并新增微信连续拼接、悬浮迷你快捷菜单、细线轨迹与 V0.4.6 的只读排版功能。本环境没有 Android SDK，未实际构建 APK，也未在 Redmi K40S 重新测试。**请在 Code on the Go 真机编译后再验证。**

请先阅读 `OPTIMIZATION_v047.md` 了解改动与局限。

## 手机更新步骤

1. 在**当前已安装版**中，分别从「知识库」「微信」导出两份加密备份，并妥善保存独立的备份口令。备份文件也应安全保存。不要卸载旧版。
2. 将本 ZIP 解压。应看到工程根目录 `OunanKnowledge_v0475`，内部有 `app/`、`settings.gradle.kts`、`build.gradle.kts` 等文件。
3. 打开 Code on the Go →「打开已保存的项目」→「从文件夹打开」→ 选择 `OunanKnowledge_v0475` 整个项目文件夹，不要单独打开 `app/`。
4. 等待 Gradle 初始化完成，点击绿色三角形。出现 `BUILD SUCCESSFUL` 后尝试**覆盖更新**当前「欧南知识中枢」。
5. 如果提示签名不同或无法覆盖，请**停止安装，不要卸载旧版**；先保存编译日志反馈。
6. 打开 APP →「设置」→「🕷 侧边迷你蜘蛛（可选）」开启待机侧边快捷入口。若需更换权限，可在系统无障碍界面重新启用「欧南 · 可见采集蜘蛛」。

## 推荐测试顺序（先用不敏感测试数据）

- **小蜘蛛**：开启侧边快捷入口 → 切到另一 APP → 边缘出现「🕷」；点击展开菜单，选择「开始知识采集」，随后出现「🕷 数字」，暂停、继续、保存并停止应能正常工作。拖动到边缘，不再占用一大块屏幕。
- **细线轨迹**：采集一篇普通网页的几个段落，跟随手动滑动，查看细线/弧线是不是只标记真的新增文字。若文字识别为 0，不应假装采集。
- **微信聊天**：选择「微信 OCR」，每次批准安卓录屏权限，输入准确会话标题。先使用测试聊天；从较早消息缓慢向下翻，每次让新旧两屏有重叠，再保存。核对“好的”等重复真实发言是否保留，前后翻页重复的文字是否被跳过，是否有“连续性待核对”提醒。微信仍不能保证完整备份。
- **文字排版**：知识库 → 任意采集记录详情 →「查看自动排版稿」，可另行导出 TXT。自动排版并不会改动或替换加密原始正文。
- **持久性**：退出并再次启动，确认记录可搜索；对加密备份完成恢复检查后，才考虑存储更重要的资料。

## 数据和隐私

- 同一包名：`com.ounan.secondbrain`；保留原数据库文件名、AES-GCM 密钥别名及 HMAC 指纹设计；版本号 `0.4.7.5 (16)`。正常同签名覆盖更新时本地数据应保留，但不能在未经测试前保证万无一失。
- 知识库和微信档案都仅在手机本地。**数据存储在 APP 私有数据目录里，不是 ZIP/APK 安装包里**；卸载或清空应用数据可能使设备绑定的加密密钥永久丢失。
- 无 `INTERNET` 权限，不会自动调用 GPT；不存在已完成的音频转文字或视频字幕采集模块。
- OCR 画面识别会有错字、漏行、乱序和误把界面文字当作聊天的可能。不能用它证明对话完整性。无法越过微信、安卓的隐私/录屏限制；系统每次录屏权限都必须由用户授权。
- 悬浮按钮只有在无障碍服务启用且用户开启待机开关时才常驻。待机时不会采集；在敏感页面请不要启动采集。
- 暂时没有安全审计过的独立密码保险箱。**不要在测试版中保存真实密码、银行资料或恢复密钥。**
